[pure virtual protected] void QCtmAbstractTitleBar::onWindowCloseButtonHint(bool showCloseButton)

在关闭按钮显示状态发生变化时调用. showCloseButton 为 true 表示应显示关闭按钮，否则表示不显示.

该函数为纯虚函数，需要子类根据窗口标志更新关闭按钮的可见状态。

[pure virtual protected] void QCtmAbstractTitleBar::onWindowMaximizeButtonHint(bool showMaximizeButton)

该函数为纯虚函数，需要子类根据窗口标志更新最大化按钮的可见状态。

[pure virtual protected] void QCtmAbstractTitleBar::onWindowMaximized(bool isMaximumSized)

在窗口最大化状态发生变化时调用, isMaximumSized 为 true 表示当前窗口已最大化，否则表示未最大化.

该函数为纯虚函数，需要子类根据窗口是否处于最大化状态更新标题栏界面。

[pure virtual protected] void QCtmAbstractTitleBar::onWindowTitleChanged(const QString &title)

该函数为纯虚函数，需要子类将窗口标题同步到标题栏显示区域。

[pure virtual protected] bool QCtmAbstractTitleBar::showIconSystemMenu(const QPoint &pos) const

显示系统图标菜单. pos 系统菜单弹出位置. 如果成功显示系统菜单则返回 true，否则返回 false.

该函数为纯虚函数，需要子类在指定位置显示系统菜单。
